## Selected Work

### [Bridger](https://github.com/ZerixNetwork/Bridger) | Founder & Maintainer

An open-source desktop application and CLI for converting Minecraft worlds and resource packs between Java and Bedrock Edition. I started Bridger as a Zerix Network fork of Hive Games' Chunker and expanded it into a broader toolkit for creators and server developers.

- Built local previews for `.schematic`, `.schem`, `.nbt`, and `.mcstructure` files.
- Added interactive textured 3D rendering with Three.js, plus 2D top and layer views.
- Implemented Java/Bedrock resource-pack conversion with format detection, archive safety limits, conversion reports, and automated tests.
- Maintain the Electron desktop experience, Java CLI, Gradle build, and cross-platform packaging.

`Java` `JavaScript` `React` `Electron` `Three.js` `Gradle` `NBT`

### [Zerix Network](https://github.com/ZerixNetwork) | CEO & Software Developer

Development work for a competitive Minecraft Bedrock network, including server-side systems, PocketMine-MP plugins, web services, and internal tooling used to support the platform and its community.

`PHP` `PocketMine-MP` `Web development` `Infrastructure`

### Zerixium | Lead Developer

A production-focused PocketMine-MP fork powering Zerix Network. I lead core architecture, protocol support, performance optimization, releases, and technical documentation while preserving compatibility with existing plugins, worlds, and build tooling.

- Continuously updated for new Minecraft Bedrock releases and protocol changes.
- Built multi-protocol support so current and older client versions can connect to the same infrastructure.
- Improved server performance and stability through production-driven core optimizations.
- Implemented core gameplay and network behaviour, including packet handling, legacy world-state migration, and compatibility fixes.
- Used PHPStan, PHPUnit, integration tests, and automated code-style checks in CI.

`PHP` `PocketMine-MP` `Multi-Protocol` `Network Packets` `Performance` `PHPStan` `PHPUnit`

### [Zerix Website](https://zerix.ml/) | Designer & Developer

Designed and developed the public web presence for Zerix Network, providing a central platform for the server, its services, and its community.
